# ixmaps (Legacy)

> ⚠️ **This repository is no longer in active development and is kept here for legacy reasons.**

## About This Framework

This ixmaps framework uses nested iframes to create maps for embedding. While maps created with this iframe-based approach continue to work, a newer and improved approach is now available.

## Migration to ixmaps-flat

The newer **[ixmaps-flat](https://github.com/gjrichter/ixmaps-flat)** framework includes all ixmaps interactive map components in one HTML5 namespace, providing a more modern and streamlined architecture.

### Recommendations

- **Existing projects**: Maps created with this iframe-based ixmaps framework will continue to function normally.
- **New projects**: It is recommended to use **[ixmaps-flat](https://github.com/gjrichter/ixmaps-flat)** instead for all new ixmaps projects.

## More Information

For detailed information about the new framework, please visit the **[ixmaps-flat repository](https://github.com/gjrichter/ixmaps-flat)**.
